# 实训学时合规与冻结服务

该服务汇聚学员签到、导师确认和请假修正事件，按培养方案与时区重放学时状态，并保存可追溯的学期冻结快照。项目还提供导师分配、证明材料、豁免复核、规则版本、名额、通知和数据留存等领域模块，供后续业务扩展时复用统一的状态与审计约束。

## 批量对账

审计场景下，可将多个培养方案的冻结快照与院校报送汇总表组成**对账批次**逐项核对，替代逐个冻结的差异查询：

- `POST /api/recon-batches/{batch_id}` 创建批次。每个批次项绑定一份冻结快照与一组外部汇总行，创建时即固定两侧的内容指纹（SHA-256）；相同批次号重复创建且指纹一致时幂等返回，外部文件更正后必须使用新批次号。
- `POST /api/recon-batches/{batch_id}/run` 运行或恢复作业。按批次项逐个比对，差异按学生、活动类型和教学日定位为异常项；每个分片提交断点，崩溃或部分失败后可断点续跑，重试幂等（确定性主键去重）。
- `POST /api/recon-exceptions/{id}/claim` 认领异常项；`POST /api/recon-exceptions/{id}/review` 复核（要求先认领、复核人与认领人不同、版本一致，并发复核只有一个成功）。
- `POST /api/recon-batches/{batch_id}/sign` 全部异常复核终结后签署批次；已签署批次拒绝重跑、认领与复核，导出结果保持不变。
- `GET /api/recon-batches/{batch_id}/export` 导出对账清单，含输入指纹、异常明细、按学生/活动类型/日期的汇总以及覆盖全部稳定字段的导出指纹。

对账接口通过 `X-Actor-Id` / `X-Actor-Role` 请求头识别操作者，角色决定权限范围：`auditor`（建批、运行、认领、导出）、`reviewer`（复核、导出）、`admin`（全部，含签署）。缺少或未知角色返回 401，越权返回 403。

## 运行方式

默认数据保存在项目目录的 SQLite 文件中。安装依赖后执行 `uvicorn app.main:app --host 127.0.0.1 --port 8000`，健康检查地址为 `/health`，业务接口位于 `/api`。

## 测试

```bash
python3 -m pytest -q
```

## 编译检查

```bash
python3 -m compileall -q app tests
```

测试覆盖事件幂等导入、跨时区与跨日学时合并、实习确认、负向修正、冻结快照和差异查询；运行过程中不需要单独的数据库或网络服务。
